Структура программ и организация кода
Поскольку создаваемый бот должен уметь работать с разными командами, можно создать несколько функций для работы с этими командами. Допустим, необходимо, чтобы Telgram-бот умел:
- реагировать на команду /start;
- принимать сообщения пользователя;
- получать информацию из внешнего API;
- обрабатывать полученные данные;
- отправлять пользователю ответ.
Тогда код в упрощённом виде будет выглядеть следующим образом: 
 
import os
import requests

TOKEN = "123456"

def start():
    print("Привет! Я бот.")

def get_data():
    response = requests.get("https://example.com/api")
    return response.json()

def process_data(data):
    result = data["temperature"]
    return f"Температура: {result}"

def send_message(message):
    print(message)

def main():
    start()
    data = get_data()
    result = process_data(data)
    send_message(result)

main()


Всё выглядит понятно до тех пор, пок ане появится ещё десятки функций, условий, настроек и т.д., из-за чего код становится трудно читать и тем более поддерживать. Для упрощения этой задачи программу длеят на файлы, например, как здесь: 
telegram_bot/
│
├── main.py
├── config.py
├── handlers.py
├── api.py
└── processing.py 
Разберём каждый файл: 
main.py – главный файл. Он отвечает за запуск программы и объединяет остальные части.
from handlers import start
from api import get_data
from processing import process_data

def main():
    start()
    data = get_data()
    result = process_data(data)
    print(result)

if __name__ == "__main__":
    main()

Здесь из папок, созданных в этой же структуре, извлекаются функции, которые вложены внутрь. То есть в первых трёх строках мы видим собственные модули. 
Далее идёт функция, которая активизирует остальные, указанные в теле def main().
Последние две строки: __name__ - это встроенная переменная Python, она автоматически получает значение в зависимости от того, как используется файл.
Есть два варианта: 
- Если мы запускаем файл непосредственно, Python присваивает __name__ значение «__main__»
- Если мы импортируем файл из другого файла, Python присваивает __name__ имя импортируемого модуля
То есть если мы запускаем файл main.py, то внутри него будет print(__name__), и в результате мы получим __main__.
И вернёмся к нашему изначальному коду: 
 
if __name__ == "__main__":
    main()

Дословно: если имя файла равно «__main__», то необходимо выполнить код внутри условия. Вот ещё пример использования такой конструкции: 
def greet():
    print("Привет!")

def main():
    print("Запускаем программу")
    greet()

if __name__ == "__main__":
    main()

Тут Python прочтёт определение greet(), татем main(), затем проверит условие и, если оно окажется истинным, вызывает функцию main(), в результате чего будет выведено «Запускаем программу. Привет!».
Таким образом, файл main.py не реализует отдельные функции, он организует их взаимодействие: запускает приветствие, вызывает получение данных, передаёт данные на обработку и выводит результат.
config.py – здесь хранятся настройки программы
Например: 

BOT_TOKEN = "123456"
MAX_MESSAGE_LENGTH = 4000
LANGUAGE = "ru"

Это необходимо для того, чтобы в случае необходимости изменения настроек не пришлось искать их по всем файлам, т.к. такие данные могут использоваться сразу в нескольких файлах.
В реальных проектах секретные данные обычно хранятся в .env, а config.py уже получает их оттуда. 
handlers.py – обработчики сообщений
Здесь располагаются функции, которые отвечают за реакцию программы на действия пользователя. Например: 

def start():
    print("Привет! Я бот.")

def help_command():
    print("Я могу помочь тебе!")

api.py – получение данных
Здесь находится логика взаимодействия с внешними сервисами.
import requests

def get_data():
    response = requests.get("https://example.com/api")
    return response.json()

Если нам потребуется изменить способ получения данных, мы будем работать с этим файлом, а не искать соответствующий код среди остальных функций.
processing.py – обработка данных
Здесь располагаются функции, которые преобразуют и анализируют полученную информацию.
def process_data(data):
    temperature = data["temperature"]

    result = f"Температура: {temperature}"

    return result

Например, API вернул данные, а эта функция извлекла нужное значение и подготовила текст для пользователя.
Теперь рассмотрим Взаимодействие файлов в архитектуре друг с другом: 
Для взаимодействия файлов используется import.
Рассмотрим для начала простой пример: 
Структура проекта: my_project/
- main.py (Запуск)
- calculator.py (Математические функции)
Файл calculator.py имеет следующее содержание: 
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

А файл main.py содержит: 
 
import calculator

result = calculator.add(5, 3)

print(result)


И теперь мы через терминал запускаем main.py: 
 
python main.py

У нас происходит следующее: файл запускается, python видит import calculator, находит в нашей структуре calculator.py и загружает его содержимое в наш модуль. Теперь нам доступны все функции из calculator.py, поэтому пишем название папки+точка+конкретная функция, в скобочках задаём значение переменным. Через print функция возвращает результат выполнения.
Существует 2 способа импорта: 
1. Импортируем весь модуль: 
import calculator
result = calculator.add(5,3)

В ЭТОМ СЛУЧАЕ МЫ ОБРАЩАЕМСЯ К ЕГО ФУНКЦИИ ЧЕРЕЗ ЕГО ЖЕ НАЗВАНИЕ
2. Импортируем конкретную функцию: 
 
from calculator import add
result = add(5, 3)

Теперь функция доступна напрямую без названия самого модуля.

Не существует одной обязательной структуры, которая подходит абсолютно всем программам. Она зависит от размера проекта, его задач и используемых технологий.
Организация Python-проекта по файлам и модулям
1. Структура проекта
Для практики мы создали небольшой проект по учёту расходов.
Вместо того чтобы размещать весь код в одном файле, разделили его на три файла:
expenses_project/
│
├── app.py
├── expenses.py
└── reports.py
Назначение файлов:
•	app.py — главный файл программы, который объединяет остальные модули.
•	expenses.py — модуль для расчёта расходов.
•	reports.py — модуль для формирования отчётов.
Разделение программы на отдельные файлы позволяет структурировать код, упрощает его поддержку и даёт возможность повторно использовать написанные функции.
2. Содержимое файлов
Файл expenses.py
Отвечает за математические операции с расходами.
print("Модуль expenses загружен")


def calculate_total(a, b):
    return a + b


def main():
    print("Проверка расходов")
    print(calculate_total(500, 300))


if __name__ == "__main__":
    main()
Здесь:
•	print() выводит сообщение при загрузке модуля.
•	calculate_total() принимает два числа и возвращает их сумму.
•	main() содержит демонстрацию работы модуля.
•	if name == "main": проверяет, запущен ли файл непосредственно.
Файл reports.py
Отвечает за формирование отчётов.
print("Модуль reports загружен")


def create_report():
    print("Отчёт сформирован")


if __name__ == "__main__":
    create_report()
Здесь:
•	create_report() — функция формирования отчёта.
•	if name == "main": позволяет запускать create_report() только при непосредственном запуске reports.py.
Файл app.py
Это главный файл, который объединяет остальные модули.
import expenses
import reports


def main():
    print("Моя программа учёта расходов")

    total = expenses.calculate_total(1000, 2000)
    print(total)

    reports.create_report()


if __name__ == "__main__":
    main()
Здесь мы:
•	импортируем два собственных модуля;
•	используем функцию calculate_total() из expenses;
•	используем функцию create_report() из reports;
•	запускаем основную программу через main().
3. Импорт собственных модулей
В Python есть несколько способов импорта.
Первый способ — импортировать весь модуль:
import expenses
В этом случае для обращения к функциям необходимо указывать название модуля:
expenses.calculate_total(1000, 2000)
Второй способ — импортировать конкретную функцию:
from expenses import calculate_total
Теперь функцию можно вызывать напрямую:
calculate_total(1000, 2000)
Разница заключается в том, что import expenses импортирует модуль целиком, а from expenses import calculate_total импортирует конкретную функцию из него.
4. Конструкция if name == "main"
Это специальная конструкция Python, которая позволяет определить, каким образом используется файл: запускается самостоятельно или импортируется в другой файл.
Для этого Python автоматически создаёт специальную переменную name.
Она принимает разные значения:
•	"main" — если файл запускается непосредственно.
•	Название модуля — если файл импортируется в другой файл.
Например:
if __name__ == "__main__":
    main()
Разберём каждую часть:
•	if — условие.
•	name — специальная переменная Python.
•	"main" — специальное значение для непосредственно запускаемого файла.
•	main() — вызов основной функции программы.
Таким образом, main() запустится только тогда, когда файл запускается самостоятельно.
Важно: значение name определяется отдельно для каждого файла.
Например, если мы запускаем app.py, который импортирует expenses.py и reports.py, значения будут следующими:
•	В app.py: name = "main".
•	В expenses.py: name = "expenses".
•	В reports.py: name = "reports".
Python присваивает значение "main" только тому файлу, который непосредственно запускается в терминале.
5. Практическая проверка: три сценария запуска
Сценарий № 1. Запускаем app.py
В терминале вводим:
python app.py
Последовательность выполнения:
1.	Python запускает app.py.
2.	Встречает import expenses.
3.	Загружает expenses.py и выводит сообщение «Модуль expenses загружен».
4.	Проверяет условие внутри expenses.py. Оно ложное, поскольку файл импортирован, а не запущен напрямую.
5.	Возвращается в app.py.
6.	Встречает import reports.
7.	Загружает reports.py и выводит сообщение «Модуль reports загружен».
8.	Условие внутри reports.py также ложное.
9.	Возвращается в app.py.
10.	Проверяет условие if name == "main".
11.	Условие истинно, поэтому запускается main().
12.	Выполняются расчёт расходов и формирование отчёта.
Результат выполнения:
Модуль expenses загружен
Модуль reports загружен
Моя программа учёта расходов
3000
Отчёт сформирован
Обрати внимание: функции main() из expenses.py и create_report() из reports.py автоматически не запускаются при импорте этих модулей.
Сценарий № 2. Запускаем expenses.py
В терминале вводим:
python expenses.py
Последовательность выполнения:
1.	Python непосредственно запускает expenses.py.
2.	Выводится сообщение «Модуль expenses загружен».
3.	Значение name становится "main".
4.	Условие if name == "main" выполняется.
5.	Запускается функция main().
6.	Выводится сообщение «Проверка расходов».
7.	Выполняется calculate_total(500, 300).
8.	На экран выводится результат — 800.
Результат выполнения:
Модуль expenses загружен
Проверка расходов
800
Сценарий № 3. Запускаем reports.py
В терминале вводим:
python reports.py
Последовательность выполнения:
1.	Python непосредственно запускает reports.py.
2.	Выводится сообщение «Модуль reports загружен».
3.	Значение name становится "main".
4.	Условие if name == "main" выполняется.
5.	Запускается функция create_report().
Результат выполнения:
Модуль reports загружен
Отчёт сформирован
6. Зачем нужна конструкция if name == "main"?
Она позволяет использовать один и тот же Python-файл двумя способами:
1.	Как самостоятельную программу, которую можно запустить непосредственно.
2.	Как модуль, функции которого можно импортировать и использовать в других файлах.
При импорте файла его обычные инструкции выполняются, определения функций и классов становятся доступными, но код внутри условия if name == "main" не запускается.
Таким образом, мы можем повторно использовать функции из одного файла в другом, не запуская автоматически основную часть программы.
7. Главные выводы
•	Python-проект можно разделять на несколько файлов и модулей.
•	Каждый файл может отвечать за отдельную часть программы.
•	Для подключения собственных модулей используется import.
•	При использовании import module обращение к функциям происходит через название модуля: module.function().
•	При использовании from module import function функцию можно вызывать напрямую.
•	Переменная name автоматически создаётся Python.
•	Если файл запускается непосредственно, name получает значение "main".
•	Если файл импортируется, name получает название модуля.
•	Конструкция if name == "main": позволяет запускать определённую часть кода только при непосредственном запуске файла.
Главная идея: разделение проекта на модули помогает организовать код, повторно использовать функции и управлять запуском отдельных частей программы.
